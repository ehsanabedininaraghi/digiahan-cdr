# نصب DigiAhan CDR v4.3.12

1. ZIP را Extract کنید.
2. روی `RUN-v4.3.12.cmd` راست‌کلیک و **Run as administrator** را اجرا کنید.
3. رمز داشبورد فعلی حفظ می‌شود. فقط اگر فایل رمز وجود نداشته باشد، نصب‌کننده رمز تازه می‌خواهد.
4. تا پیام `v4.3.12 installed successfully` پنجره را نبندید.

آدرس‌ها:

- داشبورد مدیریت: `http://192.168.8.143:5088/dashboard`
- مدیریت کاربران فروش: `http://192.168.8.143:5088/seller-admin`
- ورود فروشندگان: `http://192.168.8.143:5088/seller-v2/`
- هوش مکالمات: `http://192.168.8.143:5088/ai`

برای فعال‌کردن ورود واقعی ضبط‌های Issabel به AI باید کلید SSH و `known_hosts` آماده باشد. سپس `CONFIGURE-AI-v4.3.12.ps1` را با مسیرهای واقعی اجرا کنید و دوباره نصب‌کننده را اجرا کنید. هیچ کلید یا رمزی داخل ZIP قرار ندارد.

نصب‌کننده قبل از جایگزینی فایل‌ها Backup می‌گیرد، Build آفلاین انجام می‌دهد، سرویس را Health Check می‌کند و نسخه، صفحه فروشنده و نبود داده‌های نمایشی را بررسی می‌کند. در صورت خطا ZIP تشخیصی داخل `Logs\Runs` ساخته می‌شود.
