# نصب DigiAhan CDR v4.3.1 Hotfix

## نصب

1. فایل ZIP را داخل یک پوشه Extract کنید.
2. روی `RUN-v4.3.1.cmd` راست‌کلیک کنید و **Run as administrator** را بزنید.
3. نصب‌کننده از فایل‌های قبلی Backup می‌گیرد، برنامه فعلی پورت 5088 را متوقف می‌کند، نسخه جدید را Build و اجرا می‌کند و Health-check می‌گیرد.
4. بعد از پیام موفقیت، صفحات زیر در دسترس‌اند:

- داشبورد: `http://localhost:5088/dashboard`
- ارسال اطلاعات خرید مشتری: `http://localhost:5088/invoice-notifications`

## روش کار اعلان خرید

1. حسابداری طبق زمان‌بندی ۱۰دقیقه‌ای همگام می‌شود.
2. شماره حواله از فیلد شرح فاکتور، مثل `حواله: 40416/20`، استخراج می‌شود.
3. فاکتور از طریق کد حسابداری به `IdentityId` وصل می‌شود.
4. Primary Mobile معتبر مشتری انتخاب می‌شود.
5. مدیر فاکتور را انتخاب و متن پیامک و لینک امن را آماده می‌کند.
6. متن در این نسخه دستی ارسال می‌شود؛ سپس مدیر گزینه «ارسال شد» را ثبت می‌کند.

اگر شماره صحیح در فهرست نیست، دکمه «جدید» را بزنید. شماره جدید به همان IdentityId متصل و Primary Mobile می‌شود.

## نکته دامنه عمومی

برنامه لینک را با پیش‌فرض `https://www.digiahan.com/order/{token}` می‌سازد. برای کارکرد این لینک روی اینترنت، وب‌سرور سایت باید مسیر `/order` و `/api/public/orders` را به سرویس CDR هدایت کند. تا قبل از تنظیم Reverse Proxy، صفحه مدیریت و تولید متن کار می‌کند ولی لینک اینترنتی مشتری قابل استفاده نخواهد بود.

## امنیت

- لینک مشتری فقط توکن تصادفی دارد.
- شماره فاکتور، کد حسابداری و شناسه دیتابیس در URL یا صفحه مشتری نمایش داده نمی‌شود.
- فقط Hash توکن در SQL ذخیره می‌شود.
- برای دسترسی به صفحه مدیریت از یک سیستم دیگر، `Receiver:ApiToken` را در کادر «توکن مدیریت» وارد کنید.

در صورت خطا، ZIP تشخیصی داخل `D:\DigiAhan\CDR4.0\Logs\Runs` ساخته می‌شود.
