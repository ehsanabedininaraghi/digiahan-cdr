# نصب DigiAhan CDR v4.3.11

1. فایل ZIP را Extract کنید.
2. روی `RUN-v4.3.11.cmd` راست‌کلیک و **Run as administrator** را اجرا کنید.
3. رمز خصوصی داشبورد مدیریت را وارد کنید.
4. تا پیام `v4.3.11 installed successfully` پنجره را نبندید.

آدرس‌ها:

- داشبورد مدیریت: `http://192.168.8.143:5088/dashboard`
- مدیریت کاربران فروش: `http://192.168.8.143:5088/seller-admin`
- صفحه ورود فروشندگان: `http://192.168.8.143:5088/seller-v2/`

برای ساخت یوزر، ابتدا با رمز مدیریت وارد داشبورد شوید و «کاربران فروش» را بزنید. نام، نام کاربری، داخلی‌های متعلق به فروشنده و رمز اولیه را ثبت کنید. پس از ذخیره، متن آماده‌ی اطلاعات ورود را کپی و فقط برای همان فروشنده ارسال کنید.

کاربر غیرفعال نمی‌تواند وارد شود. تغییر رمز یا غیرفعال‌کردن کاربر، نشست‌های باز قبلی را نیز همان لحظه می‌بندد.
