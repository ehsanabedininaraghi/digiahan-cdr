نسخه داشبورد دیجی‌آهن

1) پروژه را در Visual Studio باز کنید.
2) برنامه قبلی Receiver را متوقف کنید.
3) appsettings.json را بررسی کنید. توکن فعلی: 1849Digiahan1849
4) Build و سپس Run کنید.
5) آدرس داشبورد:
   http://localhost:5088/dashboard
   یا از شبکه:
   http://IP-WINDOWS:5088/dashboard

این نسخه هیچ تغییری در جداول SQL ایجاد نمی‌کند و مستقیماً از dbo.RawCDR و dbo.SyncBatch گزارش می‌گیرد.
