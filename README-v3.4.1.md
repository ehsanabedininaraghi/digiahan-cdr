- زمان آخرین همگام‌سازی موفق
- مبلغ فروش ۳۰ روز اخیر
- تعداد فاکتورها و مشتریان خریدار
- میانگین مبلغ فاکتور
- فروش به تفکیک ویزیتور
- تفکیک نقش فروش، بین‌دفتری، مطالبات و غیرفعال
- جدول آخرین فاکتورهای فروش
- نسخه 3.4.1

اجرا:
