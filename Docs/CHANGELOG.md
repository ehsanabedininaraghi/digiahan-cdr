## v3.1.0 - 2026-08-01

- اصلاح تشخیص مشتری در تمام ردیف‌های یک تماس بر اساس `LinkedId/UniqueId`.
- تماس داخلی به داخلی دیگر «مشتری جدید» محسوب نمی‌شود.

- فیلتر «از تاریخ / تا تاریخ» اضافه شد.
- گزارش‌های روزانه، هفتگی، ماهانه و بازه دلخواه اضافه شد.
- فیلتر تک‌تک داخلی‌ها/فروشنده‌ها اضافه شد.
- جدول روند روزانه اضافه شد.
- گزارش داخلی‌ها در بازه انتخاب‌شده به تماس‌های یکتا نزدیک‌تر شد.
- نسخه صفحه و API به `3.1.0` ارتقا یافت.

# Changelog

## 3.0.0 - 2026-08-01
- بازنویسی کامل DashboardRepository.

- لاگ سراسری روزانه شامل Endpoint، SQL، پارامترها و Stack Trace.

- مقاوم‌سازی Frontend: خرابی یک API کل داشبورد را متوقف نمی‌کند.
- حفظ اتصال Issabel، SQL Server و مخاطبان دیدار.
