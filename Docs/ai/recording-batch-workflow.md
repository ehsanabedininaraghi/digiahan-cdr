# ورودی Batch ضبط مکالمه

تا زمان اتصال مستقیم به Issabel، مسیر زیر ورودی رسمی فایل‌های صوتی است:

```text
C:\Users\ehsan\Documents\ChatGPT\DIGIAHAN\recording-sample
```

فایل‌ها می‌توانند روزانه یا هفتگی، مستقیم یا در پوشه‌های تاریخ‌دار اضافه شوند. پردازش بر پایه SHA-256 است؛ بنابراین جابه‌جایی یا تکرار یک فایل باعث تحلیل دوباره نمی‌شود.

## مراحل پردازش

```text
WAV جدید
  → اعتبارسنجی WAV و محاسبه SHA-256
  → تشخیص گفتار و جداسازی سکوت/تماس قطع‌شده
  → تبدیل متن اولیه برای فایل‌های دارای گفتار
  → تفکیک مکالمه کاری، صف/IVR و موارد نیازمند بازبینی
  → کنترل کیفیت متن و حذف خروجی‌های تکراری/غیرقابل اتکا
  → استخراج موضوع، دلیل احتمالی عدم خرید، نقاط قوت و موارد حساس
  → ساخت پیشنهاد اصلاحی و خروجی بی‌نام برای داشبورد
```

متن خام، نام اصلی فایل و شماره تلفن در `batch-data.json` منتشر نمی‌شوند. داشبورد فقط شناسه بی‌نام، طبقه‌بندی، خلاصه و موارد بازبینی را دریافت می‌کند.

## اجرای افزایشی

برای اجرای همه مراحل و انتشار روی داشبورد فقط این دستور لازم است:

```powershell
.\RUN-AI-BATCH.ps1
```

فایل‌های جدید با SHA-256 شناخته می‌شوند و فایل تکراری دوباره متن‌نگاری نمی‌شود. خروجی بعد از هر فایل به‌صورت اتمیک ذخیره می‌شود؛ بنابراین قطع پردازش باعث از دست‌رفتن کارهای قبلی نمی‌شود. گزینه `-SkipTranscription` فقط خروجی داشبورد را از نتایج موجود تازه می‌کند و `-NoDeploy` از کپی خروجی روی نسخه زنده جلوگیری می‌کند.

## خروجی مربی‌گری

- تعداد مکالمه‌های قابل استفاده برای راهنمایی فروش
- کیفیت متن و جداسازی تماس‌های غیرقابل قضاوت
- موضوعات پرتکرار و دلایل احتمالی عدم خرید
- نقاط مثبت مکالمه مانند سلام، کشف نیاز، تعهد پیگیری و پایان محترمانه
- پیشنهاد اصلاحی روشن برای هر تماس
- صف بازبینی انسانی برای تنش، توهین و پرداخت شخصی/فساد احتمالی

امتیاز نمایش‌داده‌شده «پوشش اجزای مکالمه» است، نه نمره قطعی فروشنده. چون فایل فعلی تفکیک گوینده ندارد، هیچ جمله‌ای بدون بازبینی به فروشنده یا مشتری نسبت داده نمی‌شود. موارد حساس نیز فقط کاندیدای بررسی‌اند.
